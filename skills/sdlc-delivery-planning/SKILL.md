# 分批交付规划

读取本 Skill 配套资料《批次拆分与验收计划》。核对任务记录中已确认的交付范围、接口契约、业务案例和依赖顺序。回看请求只读定位并回答。按用户指令和有效授权整理、修订或推进时，更新相应任务记录。

1. 从有效功能清单、接口契约、前置条件和已确认案例映射各批交付物。
2. 每批围绕可观察的结果安排输入、必要处理、预期输出、检查与证据。说明真实或模拟依赖、排除项及受阻部分。
3. 保存 R06 的开发批次计划并更新任务入口，分别记录计划确认和当前批次授权。只有具体批次获准且开工条件满足时才可实施。
