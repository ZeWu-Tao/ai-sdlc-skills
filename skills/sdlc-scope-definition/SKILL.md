# 交付范围界定

读取[功能清单与责任边界](references/功能清单与责任边界.md)。根据任务入口、已确认需求、采用方案和实际分工界定本次交付。回看请求只读定位并回答。按用户指令和有效授权整理、修订或推进时，更新相应任务记录。

1. 核对已确认业务、采用路径、影响项和当前受委派的开发人员或团队。
2. 按可验收结果列出功能，将负责范围、预计改动对象、受影响对象和外部责任分别记录。标出无人负责或缺少承担依据的内容。
3. 实际划分时保存 `04-负责功能清单.md` 并提交人工核对。只有分工和关键依赖已确认的范围可用于后续接口设计。
