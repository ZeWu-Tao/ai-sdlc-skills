# 研发可视化制作指南

先确定读者要弄懂的关系，再选能直接回答问题的一种呈现方式。要核对分支就画分支，要看谁向谁发消息就画时序，需要自己切换或调参数时才做交互。用户明确指定形式时依其要求。下列工具是可复用的制作方法，按当前环境可用能力执行。

| 呈现方式 | 适合的场景 | 实现与交付检查 |
| --- | --- | --- |
| ① 可点击流程图 | 切换两种方案，或点某一步查看动作、条件和依据 | 用 HTML 按钮表示节点，CSS 排列连线，JavaScript 处理点击与路线切换。初始就显示一条可读路线。切换路线再点节点，检查高亮、详情和依据同步更新，窄屏和键盘也能操作。 |
| ② Canvas 2D 参数图 | 用户想试「如果改变这个值，结果会怎样」 | 用滑块或其他控件修改输入，JavaScript 按明确规则重算，Canvas 2D 重新绘图。同步显示输入和结果的文字数值，用边界输入核对单位、范围及该模型应保持的约束。示例数据标明来源或注明为模拟。 |
| ③ 可旋转三维图 | 空间或层级关系遮挡，需要换角度查看 | 为节点定义三维坐标，用 JavaScript 随旋转角度变换坐标，再投影到 Canvas 2D。检查从不同角度看时，标签可读、节点身份和连接关系一致。 |
| ④ Mermaid 分支流程图 | 审批、重试、回退或批次放行 | 用 Mermaid 的 `flowchart` 声明节点、方向及分支条件，在支持的宿主渲染。沿每个分支核对终点与回退位置。 |
| ⑤ Mermaid 时序图 | 接口联调、队列处理、异步回调及多方交接 | 用 Mermaid 的 `sequenceDiagram` 声明参与者，按实际顺序画请求、响应与事件。核对发起方、接收方，以及受理和最终结果发生在哪一步。 |
| ⑫ AI 情景插画 | 帮非技术读者理解角色、使用场景或培训案例 | 用 ImageGen 或当前环境的图像生成工具描述角色、动作和场景，生成后查看画面再展示。标明是情景示意。精确字段、数值和调用关系由项目材料核实。 |
| ⑬ 高清 PNG 流程图 | 在聊天或文档里直接分享一张准确的图 | 从核实过的 SVG 等图稿出发，用浏览器按目标像素尺寸渲染。例如通过 Playwright 驱动 Chromium 以高像素密度截图。打开导出的 PNG，检查中文、连线、边缘和缩小后的可读性。 |
| ⑭ SVG 矢量图 | 需要在不同尺寸下清楚查看架构、节点和连线 | 用 SVG 形状、文本、路径和箭头标记绘制，设置 `viewBox`。放大、缩小后检查标签位置、箭头方向和分支连接。 |
| ⑮ 单页矢量 PDF | 打印、归档或正式分享同一份架构图 | 用浏览器打印包含矢量图的页面，例如由 Playwright 驱动 Chromium，按图稿设置纸张和边距。打开成品检查页数、裁切、中文字体、文字可选取和放大清晰度。 |
| ⑯ 循环 GIF | 几个状态的先后变化值得连续播放给读者看 | 按核实的步骤逐帧绘制，可用 Python 和 Pillow 画帧，再用 FFmpeg 生成调色板并编码为循环 GIF。实际播放一轮，检查步骤顺序、标签停留时间、末帧结果及重新开始时的衔接。 |

选择后直接在对话中渲染、展示图片或交付可打开的成品。图旁给出读者最需要的结论，注明拟议、模拟或待核实的部分。用户只要一种输出时只交付所需形式。若宿主无法交互，按同一份依据提供能展示的静态图。若明确指定的格式无法生成，说明实际交付形式。确实无法渲染时，再用文字说明同一关系。
