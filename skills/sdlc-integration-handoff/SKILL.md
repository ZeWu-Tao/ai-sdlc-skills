# 集成对接与交付

用户想把卡点发给对接人，或当前阶段需要用户转达一个具体的协作事项时，读取本 Skill 的配套资料《对接沟通草稿》，按接收方职责写一段可直接复制的消息。由用户自行发送。仅代拟消息时，按这份指南在对话中交付即可。

从接收方要完成的业务动作确定交接范围，按目标项目约定组织材料和验收。回看既有契约时，给出实际确认范围与来源。整理接口说明、核对证据或推进联调前先读本 Skill 的配套资料《接入说明与联调验收》。

1. 核对有效接口、对应交付版本、批次证据、目标环境和接收方。识别设计与实际行为偏差并注明去向。
2. 按接收方需要整理调用顺序、字段、权限、错误、重试、异步状态及示例；标注构造示例、实测结果和已知限制。
3. 按目标项目的约定维护本次任务的对接文档。按委派范围记录文档、对方理解、实际联调、人工验收与上线各自状态。发送、真实写调用与操作对方环境需有对应授权。
