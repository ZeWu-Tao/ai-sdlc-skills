# 批次执行与验收记录

以一张已确认的批次执行卡为单位工作。交付时，验收人应能从同一份记录定位改动、复查实际业务结果、做出本批的验收决定。

## 判断能否开工

只读回看时，引用当前批次及相应决定，回答所问范围。用户要求实施时，从任务入口找到有效的批次计划和验收条件，核对下列事项。

| 核对对象 | 可以开工的依据 |
| --- | --- |
| 批次与授权 | 当前批次标识明确。用户指令或可核实的有效授权覆盖当前对象、操作和环境。适用时已有前一批的人工验收依据。 |
| 交付边界 | 目标、包含项、排除项、可修改范围、接口约定和预期结果可以对应到同一批次。 |
| 代码与依赖 | 已检查实际工作区、当前版本、未提交改动和本批依赖。外部资源或模拟依赖的就绪状态有依据。 |
| 验证条件 | 已确定验证场景、执行环境、数据、通过判据、证据要求和人工验收角色。 |
| 历史动作 | 已识别暂停或撤回情况，以及在途和结果未知的操作。新会话接续实施前，先提交恢复理解并取得人工确认。 |

条件满足后在既有授权内开工。发现阻塞时，记录影响范围，只推进与阻塞项无关且已授权的工作。范围重叠时先定位用户已有修改并处理冲突，保留其他人员的工作成果。

## 实现与修正

- 开工时建立批次记录，填写范围、授权、工作区基线和验收条件。每项变更都应能关联本批目标。
- 范围内的实现、调试、测试与修正可自主推进。提交、推送、合并、迁移、发布、付费调用和对外发送按各自适用的授权执行。
- 新增业务行为、修改公共契约、扩大数据或权限范围、改变环境、引入重要依赖或改动他人负责的部分时，列出已核实差异、影响、选项和待决定事项。人确认前暂停受影响的操作。
- 将历史缺陷和后续功能另列。当前批次受阻时，继续执行其他批次需要对应的放行决定。
- 查明测试本身错误时说明依据并修正。涉及已确认预期的改变必须由人决定，保留原条件、修改原因和对既有验收的影响。

## 执行验证并绑定证据

按预先确认的场景执行，在实际交付的提交、构建或可核对的工作区差异上检查可观察结果。比如验收条件为“草稿保存后仍能读取”时，记录保存返回的草稿标识，按本批约定重新读取同一条草稿，核对正文及归属。若外部存储由模拟实现替代，结论限于模拟边界。

每个必要场景记录以下内容。

| 场景与预期 | 运行对象 | 实际观察 | 结论与证据 |
| --- | --- | --- | --- |
| 需求或验收条件、成功或关键异常路径 | 版本、环境、命令或操作、数据、真实或模拟依赖 | 返回值、读回状态、交付物或副作用 | 通过／失败／进行中／受阻／未执行、证据位置及限制 |

有限运行以相应场景完成为准。常驻服务按约定的场景或观察窗口记录结果。生成质量检查沿用约定的样本和判据，保留失败样本与未验证部分。工具中断、请求已受理或检查未运行时，如实记录实际状态。

验收前检查代码差异，对照本批包含项和排除项。代码有实质修改时重验受影响行为，说明哪些旧证据仍适用。报告失败原因时区分已核实原因与推断。对证据中的凭据和无关业务数据做必要脱敏。

## 提交人工验收

按“批次和版本、实际结果、差异和验证证据、限制、请人检查的事项”交付。必要条件满足时登记为“待人工验收”。未达到条件时提交局部结果或阻塞说明，并标出欠缺的证据。

| 人工反馈或任务状态 | 处理 |
| --- | --- |
| 本批未通过，问题在原范围内 | 记录反馈和原失败事实。修正本批，重测受影响场景，提交新版本复验。 |
| 反馈要求新行为或更改验收条件 | 标明原约定、影响和建议，取得对应决定后更新范围与验收依据。 |
| 仅确认部分结果或有条件接收 | 记录具体版本、已确认部分、保留条件、剩余责任和处理安排。 |
| 当前版本已由人明确验收 | 更新批次记录。下批获得独立授权且其前置条件满足时方可开工。 |
| 已验收版本再次发生实质变化 | 保留旧版本的结论，重验并提交受影响部分确认。 |

人工验收与下一批授权分别记录。一条明确指令可同时覆盖两个决定。AI 自测、其他 AI 的评审、报告已发送和用户无回复均不得记作人工验收。等待验收期间若依授权修正了本批，须更新版本与证据，向验收人指明当前交付对象。

## 处理中断和结果未知的操作

收到暂停、停止或撤回指令时，停止新增相应操作。列出已完成、在途、结果未知的动作和可安全取消的部分。恢复前按当前授权查询原请求、任务、资源或持久化结果。禁止通过再次写入、发送或发布来探测上次操作是否成功。无法核实的结果保持待核查。取消请求、执行终止、代码回退、数据恢复和外部补偿各自需要对应依据和授权。

## 保存记录并交接

按目标项目约定维护当前批次的执行记录，注明批次标识，并把实际批次、授权和验收状态同步到任务入口和开发批次计划。本期工作结束时，将实际版本、已验收功能、有效接口、验证证据和未完成事项交给对接负责人。外部联调或发布遵循相应环境和操作授权。
