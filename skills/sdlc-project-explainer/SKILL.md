# 项目实现讲解

读取本 Skill 的配套资料《讲解范围与证据使用》。本 Skill 的操作限于读取项目资料和在对话中讲解。

1. 从用户的描述、页面操作、代码位置或改动记录定位功能或技术点，判断用户想听什么。存在会改变答案的歧义时，提出有具体选项的确认问题，等待回复后再深入。范围明确时，用一句话说明本轮讲解范围并继续。
2. 对照相关代码、有效阶段文档及改动记录。按实际证据说明当前怎么跑、当时为什么这样选，或这次改动前后有什么变化。
3. 首轮用白话讲清一个完整场景和影响理解的关键细节，给出相关依据。收到追问时沿已确定的对象展开相应部分。
