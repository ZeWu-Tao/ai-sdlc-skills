# 改动方案确认

读取[改动方案与复测计划](references/改动方案与复测计划.md)。用只读方式核对排查结论、当前实现和仍有效的任务文档。

1. 先讲清问题原因和关键证据，标出仍会影响选方案的疑问。已有证据直接沿用。
2. 提出具体改法，分别说明原问题影响哪里、本次改动会影响谁，以及需要同步的文档、预期可见结果和复测判据。
3. 把拟确认的改法、范围、文档和复测标准交给用户。提交方案后停止，等待明确确认。

用户需要先和对接人确认改法、兼容要求或复测安排时，把相关内容写成具体的待确认事项，给一段可直接复制的正文，由用户自行发送。可用时参考[对接沟通草稿](../sdlc-integration-handoff/references/对接沟通草稿.md)。

本 Skill 只交付方案。业务代码、测试、配置、数据、分支及已有业务文档都保持原状。用户明确要求保存时，可按项目约定写单独的方案记录。确认方案后，实施仍按项目约定核对批次授权和分支选择。
