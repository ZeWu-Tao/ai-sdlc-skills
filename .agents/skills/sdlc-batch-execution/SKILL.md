# 批次实施与验收

定位当前批次及其有效授权，按目标项目的约定实施、验证和交付。只读查询批次状态时，引用实际记录和对应版本。实施或验收前先读[批次执行与验收记录](references/批次执行与验收记录.md)。

1. 核对批次标识、计划版本、实际工作区、前批验收、当前授权及环境限制。用户只询问进度或缺少必要授权时，报告已核实状态和开工缺项。
2. 在已获准的批次边界内完成实现、验证与修正。越界时暂停受影响操作。对已执行或结果未知的外部写入，优先在授权内核查状态。
3. 在任务的 `batches/NN-批次名称.md` 记录修改、交付版本、实际测试、限制和未验证内容，并提交人工验收。将验收结论和下一批放行分别记录。
