# 接口契约设计

读取[接口契约设计指南](references/接口契约设计指南.md)。从当前任务负责的业务结果、调用方和提供方出发，核对已确认场景、接口现状、项目约定与授权。回看请求只读定位并回答。按用户指令和有效授权整理、修订或推进时，更新相应任务记录。

1. 定位负责功能、关键业务案例、已有接口和版本兼容条件。明确调用方、提供方和本次设计范围。
2. 描述真实交互边界及失败语义。分类核对契约依赖、实现依赖、调用顺序和验证依赖，在同一可推进集合内比较复杂度。
3. 实际设计时保存 `05-接口设计.md`，标记设计示例、未协调契约和未就绪资源。人确认设计范围与排序后再进入批次规划。
