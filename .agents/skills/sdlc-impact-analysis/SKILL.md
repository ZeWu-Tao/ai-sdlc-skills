# 变更影响分析

开始时读取[影响评估与方案取舍](references/影响评估与方案取舍.md)，按目标项目的适用约定处理当前请求。已有任务按任务 README 定位有效阶段文档和当前授权。回看请求直接给出已确认结论及出处。仅当用户要求整理、修订或正式推进时，按授权写入相应任务记录。

1. 以已确认业务要求、现状证据和用户既定路径为起点。逐项定位改动对象、消费者、旧数据、在途状态及环境依赖。
2. 比较可行路径的兼容性、成本、验证和恢复条件。指出哪些事实仍需核验，以及结果会怎样影响选择。
3. 实际分析时保存 `03-改动与影响范围.md`，提交方案和处理顺序供人决定。迁移或底层试验须受具体批次、环境及操作授权约束。
