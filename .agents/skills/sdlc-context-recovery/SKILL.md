# 任务上下文恢复

按目标项目的约定定位任务入口。维护记录或恢复实施前先读[任务记录与会话恢复](references/任务记录与会话恢复.md)。仅查询历史决定时，引用主要记录、实际确认对象和范围。

1. 区分阶段记录维护与会话恢复。维护时将已确认决定及依据写入主记录，保留草稿、替代关系和未决项，再同步任务 README。
2. 恢复时先确认项目及任务身份，按入口读取有效阶段和批次记录，核对工作区、暂停指令、已完成或结果未知的操作。仅用获准的方式核查未知动作。
3. 向人提交恢复回执，列出目标、排除项、正式阶段、当前批次、证据、授权与拟继续的动作。待人明确确认接续且对应授权有效、启动条件满足后恢复该范围；仍然有效的暂停须有人明确解除。
