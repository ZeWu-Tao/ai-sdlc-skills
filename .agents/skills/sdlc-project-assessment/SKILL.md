# 项目现状评估

开始时读取[现状调查与证据记录](references/现状调查与证据记录.md)，按目标项目的适用约定处理当前请求。已有任务按任务 README 定位有效阶段文档和当前授权。回看请求直接给出已确认结论及出处。仅当用户要求整理、修订或正式推进时，按授权写入相应任务记录。

1. 以用户指定的功能、资料和参考对象为起点。已有任务优先核对有效调研结论，新任务按目标限定检索范围。
2. 只读追踪关键入口、调用链、复用条件和约束。为关键判断标出来源，将未读取资料、静态推断和运行证据分别说明。
3. 实际调研时保存 `01-现有项目理解.md`，更新或建立当前任务 README。提交现状回执和具体确认事项。人确认后可进入需求理解。
