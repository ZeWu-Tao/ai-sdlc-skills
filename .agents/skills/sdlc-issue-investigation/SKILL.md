# 问题排查

读取[问题排查与证据汇报](references/问题排查与证据汇报.md)，按目标项目适用的约定开展只读排查。

1. 对齐用户实际看到的现象和预期结果，定位相关任务记录、代码及对应版本的运行证据。
2. 只问能缩小范围、验证判断或补足证据的问题。说明需要这条线索的用途，已有信息直接沿用。出现会改变判断方向的发现时，及时用白话同步。
3. 汇报原因和证据的对应关系，区分已证实的影响、可能的影响和待核实的部分。原因未证实时，汇报已查到哪里，指出最能推进排查的下一条线索。

本 Skill 的交付点是排查报告。汇报后结束排查，保持代码、配置和业务状态不变。仅排查时等待用户决定下一步；入口编排已收到修复、优化或拟定方案的明确请求时，可将已汇报且有足够证据的结论交给方案阶段。用户明确要求保存排查记录时，可按项目约定写入该记录。
